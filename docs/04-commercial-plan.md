# 04. 상용화 계획

> 학교와 기관이 바로 쓰는 블루카본 교육 게임. 설치·로그인·개인정보 수집 없이 수업 한 차시에 한 판이 끝나요.

## 누가 사나요

| 고객 | 쓰는 곳 | 상품 | 가격 모델 (예시) |
|---|---|---|---|
| 학교·교육청 | 과학·사회·환경 수업, 창의적 체험활동 | 학교 라이선스 + 수업 자료 | 학교당 연간 구독 |
| 해양 기관·지자체 | 갯벌센터, 해양 전시관, 체험관 | 전시용 관람객 모드(키오스크) | 설치당 + 유지보수 |
| 기업 ESG | 블루카본 복원 사업 홍보, 임직원 교육 | 맞춤 시나리오(지역·사업 반영) | 프로젝트 단위 |
| 해외 | 맹그로브·염습지 교육 | 현지화 지도·언어 | 국가별 라이선스 |
| 개인 | 가족·학생 | 앱·PC 단품 (광고·확률형 아이템 없음) | 1회 구매 |

## 차별점

- **규칙이 곧 과학**: 퀴즈 대신 진흙 속 탄소, 매립 배출, 생태계 연결을 직접 겪어요.
- **한국 갯벌에 맞춤**: 세계유산 갯벌 지역과 블루카본 정책 이야기에 바로 연결돼요.
- **수업에 맞춤**: 수업 코드, 결과 코드로 모으는 학급 리포트, 엔딩별 토론 질문, 수업안.
- **어디서나**: 의존성 없는 웹 약 200KB, 오프라인 한 파일, 저사양 자동 조절.
- **안전**: 개인정보 수집 없음, 광고·결제 유도 없음, 음원도 자체 합성.

## 지금 상태 (v0.2)

| 영역 | 내용 |
|---|---|
| 게임 | 25년 캠페인, 난이도 3, 미션 14, 업적 12, 엔딩 6, 생물 12종 |
| 연출 | CO₂ 흡수, 태풍 해일, 생물 등장, 칸 반응 이펙트, 효과음·파도·음악 |
| 수업 | 수업 코드, 결과 코드, 교사용 학급 리포트(엔딩 분포·회의 선택 비율·CSV) |
| 품질 | 자동 테스트 14개, 전략별 밸런스 점검, PC·휴대폰·다크 모드 확인 |

## 출시 전 체크리스트

- [ ] 해양생태·탄소 전문가 감수 (수치, 용어, 생물 정보)
- [ ] 학생 플레이테스트 3회 + 사전·사후 개념 검사
- [ ] 접근성 점검 (키보드, 색 대비, 화면 낭독)
- [ ] 보급형 크롬북·태블릿 성능 (30fps 이상)
- [ ] 글꼴·음원 권리 확인 (글꼴 OFL, 음원 자체 합성)
- [ ] 배포: 학교망에서 열리는 주소 + 오프라인 패키지
- [ ] 교사 안내 1쪽 + 10분 연수 영상
