# 05. 캐주얼 전환: 갯벌 수호대

> 받은 피드백: 게임 화면이 작고 나머지는 글과 설명뿐이다. 교육에 치우치지 말고, 재미가 먼저다. 가장 단순하면서 중독성 있게.

## 무엇이 바뀌었나

| | 이전 (블루복셀: 갯벌마을 2050) | 지금 (갯벌 수호대) |
|---|---|---|
| 장르 | 턴제 복원 전략 + 마을 회의 카드 | 생존 액션 (뱀서라이크) |
| 조작 | 칸 고르기, 도구 고르기, 카드 읽기 | 아무 데나 드래그해서 이동. 공격은 자동 |
| 한 판 | 25년 (수업 한 차시) | 5분 |
| 화면 | 지도 1/3, 글과 패널 2/3 | 화면 전체가 게임. 글은 숫자와 짧은 말 |
| 배움 | 설명을 읽고 선택 | 해 보면서 눈으로 봄 |

전략 버전은 `prototype/`에 그대로 두었어요. 토론 수업이 필요할 때 쓰면 돼요.

## 왜 뱀서라이크인가

| 후보 | 근거 | 판단 |
|---|---|---|
| 뱀서라이크 | 국내 학생에게 익숙한 장르(탕탕특공대), PC에서도 대흥행(Megabonk 2주 만에 100만 장) | **채택**. 엄지 하나로 조작, 5분 한 판, 레벨업마다 고르는 재미 |
| 블록 퍼즐·머지 | 2026년 캐주얼 매출에서 퍼즐 비중이 가장 큼 | 탈락. 규칙이 추상적이라 "갯벌이 살아난다"를 몸으로 느끼게 하기 어려움 |
| 랜덤 디펜스 | 국내 매출 1위급 전략 게임(운빨존많겜) | 탈락. 확률 뽑기에 기대는 구조라 교육용으로 부적합 |

뱀서라이크는 "움직이며 영역을 바꾼다"는 점이 갯벌 복원과 그대로 겹쳐요. 쓰러뜨린 자리가 되살아나니 점수판을 보지 않아도 내가 바꾼 땅이 보여요.

## 재미 구조

| 시간 | 무엇이 반복되나 |
|---|---|
| 30초 | 이동 → 자동 공격 → 파란 결정 줍기 → 레벨업, 카드 3장 중 1장 (새 생물 친구 또는 강화) |
| 5분 | 1:00 포위 · 2:00 거대 몬스터와 보물 상자 · 2:30 미세플라스틱 떼 · 3:00 태풍(번개가 적을 침) · 3:35 거대 몬스터 · 4:00 포위 · 4:30 보스 |
| 며칠 | 진주로 기지 강화 9종, 생물 4종 해금, 스테이지 3개, 도감 34칸, 스테이지별 최고 기록 |

한 판 안에서 힘이 계속 커지고(무기 8종 × 5단계 + 진화 8종), 저녁이 될수록 하늘이 노을로 바뀌며 보스가 다가와요. 확률형 아이템, 광고, 결제 유도는 없어요.

## 글 없이 넣은 생태 메시지

| 게임 규칙 | 담긴 이야기 |
|---|---|
| 오염 몬스터를 쓰러뜨린 자리가 회색 → 갈색 갯벌 → 초록·붉은 염습지로 자라요 | 오염을 걷어 내면 갯벌에 생명이 돌아와요 |
| 파란 결정 = 탄소, 점수 단위 = 블루카본 t | 갯벌과 염습지가 탄소를 붙잡아 둬요 |
| 염습지·잘피 위에 서 있으면 체력이 차올라요 | 건강한 갯벌이 생물을 지켜요 |
| 기름 덩어리가 지나간 갯벌은 다시 더러워져요 | 기름 오염은 복원한 곳도 망가뜨려요 |
| 매립 불도저가 지나가면 콘크리트가 되고 CO₂가 피어올라요 | 갯벌을 메우면 저장된 탄소가 빠져나가요 |
| 보스를 이기면 매립지까지 갯벌로 돌아와요 | 역간척과 복원 |
| 무기가 칠게·바지락·잘피·짱뚱어·저어새·상괭이·갯지렁이·밀물 | 우리 갯벌의 생물과 현상 |

말로 하는 설명은 처음 한 번만 뜨는 한 줄 팁 4개와 결과 화면의 한 줄 지식, 도감뿐이에요. 해양 소양 게임 연구에서도 즉각적인 피드백과 성장 같은 게임 요소가 학습 경험을 끌어올렸어요.

## 수치 (자동 조종 기준)

`npm run balance` 결과의 요약이에요. 사람이 하면 보통 더 잘 피하지만, 처음 하는 학생에게는 비슷한 감각이에요.

| 스테이지 | 강화 없음 | 강화 중간 이상 |
|---|---|---|
| 1 갯벌 | 약 3판 중 2판 클리어 | 거의 모두 클리어 |
| 2 바다숲 | 대부분 3~4분에 쓰러짐 | 4판 중 3판 클리어 |
| 3 기름 바다 | 2~3분에 쓰러짐 | 절반 이상 클리어 |

첫 스테이지는 첫날 깰 수 있게, 뒤 스테이지는 기지 강화를 모아야 깰 수 있게 맞췄어요. 한 판에 진주 70~400개, 첫 강화는 60개부터예요.

## v0.4에서 늘린 것

| 영역 | 내용 |
|---|---|
| 캐릭터 | 칠게를 큰 눈·볼터치의 마스코트로 다시 그림, 새 친구 점박이물범(첫 판을 마치면 해금, 튕기는 물범 공) |
| 무기·패시브 | 물범 공(적 사이를 튕김), 해마 거품(따라가서 터짐), 낙지 먹물(느려지는 구름), 보름달(치명타), 해초(지속 시간), 산호(개수) |
| 스테이지 | 4 하구(녹조·폐타이어, 보스 녹조 괴물), 5 제주 바다(불가사리·열덩이, 보스 바다 열돔: 지나간 산호가 하얗게 변함) |
| 오래 하기 | 스테이지마다 별 난이도 5단계, 클리어한 스테이지의 무한 모드(보스가 계속 나와요), 업적 20개와 진주 보상 |

**최적화.** 느린 휴대폰을 흉내 낸 측정(CPU 4배 느리게)에서 한 장면 그리기가 약 195ms → 19ms로 줄었어요. 빛 입자가 장면마다 새 그림을 만들던 문제를 고치고, 땅은 8×8칸 조각으로 미리 그려 두고, 피해 숫자는 미리 그린 글자판을 쓰고, 화면 화소 수에 상한을 뒀어요. 기기가 느리면 저사양 모드로 저절로 바뀌어요.
