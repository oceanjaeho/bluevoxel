## 1. 한 줄 요약

**갯벌 수호대**는 손가락 하나로 움직이는 5분짜리 생존 액션 게임(뱀서라이크)이에요. 공격은 자동이고, 레벨업 때마다 카드 3장 중 1장을 골라요. 오염 몬스터를 쓰러뜨린 자리마다 회색 오염 갯벌이 초록 갯벌로 되살아나요. 블루카본(갯벌·염습지·잘피가 붙잡는 탄소)의 의미가 설명 없이 게임 규칙 안에 들어 있어요.

- 형태: 웹(HTML5 Canvas 2D), 설치 없음, 한 파일 빌드 약 296KB, 외부 라이브러리 없음
- 대상: 모든 연령. 돈을 내는 사람은 10대 후반~30대 게임 이용자와 아이를 둔 부모로 보고 있어요.
- 언어: 한국어만 (사용자가 영어는 지금 필요 없다고 했어요)

### 사용자가 정한 원칙

1. **재미가 먼저.** 교육은 규칙 안에 녹이고 설명하지 않아요.
2. **글은 최소.** 화면 전체가 게임이고, 글은 숫자와 짧은 말만 써요.
3. **가장 단순하면서 중독성 있게.** 조작은 드래그 하나예요.
4. **상업적으로 팔리게.** 학교·반 대항전은 돈이 안 되니 모든 연령을 노려요. 학생이 쓸 돈이면 부모가 결제자예요.
5. **귀엽고 대중적인 캐릭터.**
6. **빨리 출시.** 사용자는 혼자 끌고 가는 쪽을 원하고, 개발자·디자이너·예산은 따로 있어요.
7. 영어는 지금 필요 없어요.

### 아직 정하지 않은 것

- **가격 모델.** 제안은 한 번 구매형(Steam 유료, 모바일은 무료 시작 + 전체 해금 구매)과 광고·확률형 뽑기 없음이었어요. 사용자 확정은 아직 없어요.
- **부모·아이 2인 협동 모드** 여부.
- **출시 플랫폼 순서.** 웹 공개 → Steam → 모바일 순으로 제안했고, 아직 확정 전이에요.

## 4. 게임 설계 상세 (v0.5)

### 4.1 지도와 복원 규칙 (게임의 정체성)

- 지도는 60×60칸(한 칸 32px)인 섬이에요. 가장자리는 바다, 안쪽에 갯골(물길)이 구불구불 흘러요. 출발 지점에는 작은 초록 갯벌이 있어요.
- 칸 종류: `SEA` 바다(못 들어감), `CREEK` 더러운 물길, `DIRTY` 회색 오염 갯벌, `MUD` 되살아난 갈색 갯벌, `MARSH` 초록 염습지, `POOL` 깨끗한 물길(잘피), `CONCRETE` 매립지
- **원인과 결과**

| 보이는 것 | 규칙 | 숫자 |
|---|---|---|
| 회색 땅에 검은 웅덩이가 끓고 몬스터가 솟아나요 | 생성되는 몬스터의 35%는 화면 안 회색 칸(나와 200px 이상 떨어진 곳)에서 0.9초 예고 뒤 나와요 | `C.EMERGE` |
| 솟아나기 전에 그 칸을 살리면 몬스터가 못 나와요 | 예고가 끝날 때 칸이 회색이 아니면 취소돼요 | `updatePend` |
| 몬스터를 쓰러뜨리면 그 자리가 살아나요 | 반경 30+몬스터 크기(px) 안의 DIRTY→MUD(+1t), CREEK→POOL(+2t) | `restoreAt` |
| 갈색 갯벌이 초록 염습지로 자라요 | MUD는 4~9초 뒤 MARSH(+2t) | `updateTiles` |
| 초록 갯벌 위에서 강해져요 | 초당 회복 2.2, 공격 간격 타이머 1.2배 빠름, 몬스터 이동 0.8배 | `MARSH_REGEN`, `MARSH_HASTE`, `MARSH_SLOW` |
| 복원율 게이지 단계 보상 | 15% 바로 레벨업 · 30% 보물 상자 · 45% 저어새 떼(화면을 가로지르며 공격) · 60% 체력 전부 회복 + 상자 · 75% 대조기(화면 몬스터 정리) | `MILESTONES` |
| 생명이 돌아와요 | 초록 칸에 작은 칠게·저어새·짱뚱어가 나타나요 (그림만, 규칙 없음) | `render.js drawCritters` |
| 다시 오염돼요 | 기름·녹조·열덩이는 지나간 MUD를 DIRTY로, POOL을 CREEK로 되돌려요 | `polluteAt` |
| 매립하면 탄소가 빠져나가요 | 매립 불도저가 지나간 칸은 콘크리트가 되고 블루카본이 줄어요(MARSH −3, POOL −2, MUD −1). "CO₂" 연기가 올라요 | `paveAt` |
| 산호 백화 | 바다 열돔의 열 고리가 지나가면 MARSH→MUD→DIRTY | `bleachAt` |
| 승리 | 보스를 쓰러뜨리면 물결이 퍼지며 매립지까지 전부 갯벌로 돌아와요 | `updateVictory` |

- 점수 **블루카본(t)** = 주운 결정 값 + 복원·성장 칸 보너스. 결과 화면에는 처음/지금 지도와 복원율이 나와요.

### 4.2 성장

- 결정: 일반 1, 큰 몬스터 4+, 거대 몬스터 30. 한 화면 최대 300개이고, 넘치면 합쳐져요.
- 필요 경험치: `L<20 ? 5+(L−1)×11 : 215+(L−20)×22`. 자동 조종 기준 한 판 끝에 레벨 30~40이에요.
- 레벨업 카드 3장(가중 무작위)
  - 무기는 최대 6개, 패시브도 최대 6개, 둘 다 5단계까지 올라요.
  - 무기 5단계에 짝 패시브가 있으면 **진화** 카드가 반드시 나와요.
  - 기지 강화로 다시 뽑기를 할 수 있어요.
- 치명타 기본 6%, 2배 피해예요.

| 검은 유조선 | 기름 바다 | 거리를 두고 돌며 기름 웅덩이와 기름통 폭격 |
| 녹조 괴물 | 하구 | 녹조 방울 고리 소환, 독 녹조 웅덩이, 체력 절반 이하면 포자탄 |
| 바다 열돔 | 제주 바다 | 퍼지는 열 고리(닿으면 피해, 지나간 산호 백화), 열덩이 소환 |

- 거대 몬스터: 체력 14배, 크기 2배, 피해 1.6배이고 보물 상자를 떨어뜨려요.
- 보스가 나오고 90초 안에 못 잡으면 분노해요.

### 4.7 스테이지 5

| # | 이름 | 테마 | 체력·피해 배율 | 보스 | 해금 |
|---|---|---|---|---|---|
| 1 | 갯벌 | 서해 갯벌, 매립지 블록 | 1.0 / 1.0 | 매립 불도저 | 기본 |
| 2 | 바다숲 | 동해 바닷속, 갯녹음 바위 → 해초 숲, 빛줄기 | 1.45 / 1.2 | 유령그물 문어 | 1 클리어 |

| 4 | 하구 | 녹조, 갈대 | 1.55 / 1.25 | 녹조 괴물 | 3 클리어 |

- 몬스터 체력 = 기본 × 스테이지 배율 × (1 + t/80 + (t/240)²) × 별 배율.

- 시간이 갈수록 화면이 노을로 물들어요.

### 4.8 아이템과 즉시 재미

| 아이템 | 효과 | 얻는 곳 |
|---|---|---|
| 하트 | 체력 30% | 처치 1.1%, 쓰레기 더미 |
| 자석 | 결정을 전부 끌어옴 | 처치 0.35%, 쓰레기 더미 |
| 큰 물결 | 화면 속 몬스터 정리, 보스 6% 피해 | 처치 0.15%, 쓰레기 더미 |
| 소라 나팔 | 6초 동안 몬스터 정지(닿아도 안 다침) | 처치 0.15%, 쓰레기 더미 |
| 진주 주머니 | 진주 8~20 × 스테이지 배율 | 처치 0.12%, 쓰레기 더미 |
| 저어새 깃털 | 8초 이동 1.45배 + 무적 | 처치 0.12%, 쓰레기 더미 |
| 보물 상자 | 강화 1·3·5개 (진화 우선) | 거대 몬스터, 복원 단계 |

- **쓰레기 더미:** 처음에 14개가 있고 22초마다 1개씩 늘어 최대 16개예요. 부수면 아이템이 하나 나오고 반경 58px가 깨끗해져요.
- **콤보:** 처치 사이 2.2초 안에 이어져야 해요. 50·100·200·300·500·800·1200을 넘을 때마다 진주 (단계 ÷ 20)를 줘요.
- **태풍:** 3:00부터 22초 동안 바람이 밀고, 번개가 0.75초마다 화면 속 적을 쳐요.

### 4.9 메타 (오래 하기)

- **진주(재화):** round((처치×0.022 + 블루카본×0.008 + 초×0.12 + 승리 60 + 무한 보스×60 + 보너스) × (1+0.5×(스테이지−1)) × (1+0.3×(별−1)) × (1+0.1×진주 강화))
- **기지 강화 9:** 체력·공격·이동·자석·회복·성장·새로고침·진주·부활. 전부 사는 데 약 7,300 진주예요.
- **별 난이도 1~5:** 별 하나마다 몬스터 체력 +35%, 피해 +12%, 마릿수 +8%, 진주 +30%이에요. 앞 별을 깨야 다음 별이 열려요.
- **무한 모드:** 클리어한 스테이지에서 쓸 수 있어요. 보스가 200초마다 더 튼튼해져서 다시 나오고, 사건이 반복되고, 마릿수가 계속 늘어요.
- **업적 20:** 판 수, 클리어, 처치, 진화, 레벨, 블루카본, 복원율, 태풍, 별, 무한, 캐릭터, 도감. 진주 30~500을 보상으로 줘요.
- **오늘의 도전:** 날짜 시드로 같은 지도를 써요.
  - 스테이지는 해금된 것 중에서, 캐릭터는 해금된 것 중 무작위로 정해져요.
  - 규칙 2개가 붙어요. 규칙 후보는 날쌘 몬스터, 단단한 몬스터, 몬스터 무리, 강한 자석, 쓰레기 대청소, 유리 대포, 빠른 성장이에요.
  - 하루 첫 완료 보상은 진주 80, 클리어하면 160이에요.
- **꾸미기:** 밀짚모자 300 · 선글라스 300 · 왕관 800 진주. 모든 캐릭터에게 씌울 수 있어요.
- **도감 46칸:** 캐릭터, 무기, 패시브, 몬스터마다 한 줄 지식이 있어요. 전체 51문장이에요.

### 4.10 화면과 소리

- **타이틀:** 뒤에서 자동 조종 시연이 돌아가요. 아래쪽에 캐릭터 카드, 스테이지 칩, 별, 무한, "출동!", 진주·기지·도전·도감·소리 버튼이 있어요.
- **게임 중 화면(HUD)**
  - 위쪽: 경험치 바, 레벨, 시계, 복원율 게이지(단계 눈금), 처치 수, 블루카본, 콤보, 일시정지.
  - 무기·패시브 아이콘: PC는 위쪽, 휴대폰은 왼쪽 아래에 있어요.
- **보조 표시:** 알림 글은 짧게(예: "포위!", "갯벌 45%"), 처음 몇 판만 한 줄 팁이 나와요. 화면 밖 보스·상자·아이템은 가장자리 화살표로 알려요.
- **연출:** 화면 흔들림, 번쩍임, 큐브 파편, 칸이 되살아날 때 튀는 효과, 피해 숫자, 노을, 태풍 비, 승리 물결이 있어요.
- **소리:** 모두 Web Audio로 합성했고 녹음 파일은 없어요. 효과음 약 50종에 음악은 3가지(타이틀, 게임, 보스)이고, 게임 음악은 시간에 따라 악기가 쌓여요.
- **글꼴과 색:** Black Han Sans와 Jua(Google Fonts)에 어두운 바다 색 한 가지 테마예요. 한국어만 지원해요.

## 5. 기술 구조

### 5.1 원칙

- 빌드 도구와 외부 라이브러리 없이 순수 JS로 짰어요. 전역 `window.GS` 하나를 쓰는 클래식 스크립트라 `file://`로도 돌아가요.
- **시뮬레이션은 화면과 완전히 분리돼 있어요.** `sim.js`는 DOM 없이 노드에서도 돌고, 1/60초 고정 간격이에요. 시드(mulberry32)가 같고 입력이 같으면 결과도 같아요.
- 시뮬레이션은 사건을 `s.fx` 배열에 쌓아요. `main.js`가 매 장면 이를 비우며 화면(`render.fx`), 소리(`audio.play`), UI(`ui.fx`)에 나눠 줘요.
- 아트는 전부 코드로 만든 복셀 모델이에요. `art.js`에서 `def(name, 크기, 프레임 수, 만드는 함수)`로 정의하고, 필요할 때 화면 배율에 맞춰 스프라이트로 구워요. 그림 파일은 없어요.

### 5.5 성능 구조

- **땅:** 바다는 반복 무늬 한 번으로 그려요. 물길은 칸마다 움직이게 그리고, 땅은 8×8칸 조각 캔버스에 캐시해요. 시뮬레이션이 바뀐 조각에 `dirtyCh` 표시를 하면 한 장면에 3개까지만 다시 그려요.
- **그림:** 스프라이트는 필요할 때 굽고, 판을 시작할 때 그 스테이지 몬스터를 미리 구워요.
- **이펙트:** 빛 입자는 한 번에 몰아서 더해 그리고, 피해 숫자는 미리 그린 글자판을 써요. 한 장면에 새 피해 숫자는 14개까지예요.
- **화면 크기:** 캔버스 화소를 최대 약 2.6메가픽셀로 제한해요. 노을과 비네트는 미리 구운 그림 한 장이에요.
- **자동 저사양 모드:** 4초 평균이 약 38fps 아래면 화소 밀도 1, 입자 상한 260으로 바뀌어요.
- **계산:** 가장 가까운 적은 공간 격자로 찾고(150→320px 고리), 몬스터끼리는 살짝 밀어내요.

### 5.6 실행·검증

## 7. 알려진 한계와 위험

1. **사람 플레이테스트가 없어요.** 난이도, 첫 1분 이해도, 팁 효과, 재도전률은 모두 추정이에요.
2. **실기기 성능 측정이 없어요.** 저가 안드로이드 기기가 특히 확인 필요해요.
3. **서버가 없어요.** 랭킹·계정·클라우드 저장이 없고, 오늘의 도전 기록도 내 기기에만 남아요. 브라우저 저장을 지우면 진행이 사라져요.
4. **결제가 없어요.** 가격 모델이 미정이고, 꾸미기도 진주로만 사요.
5. **진주를 쓸 곳이 부족해요.** 열 몇 판이면 기지 강화가 끝나요.
6. **한 줄 지식 51문장이 전문가 감수 전이에요.**
7. **접근성이 약해요.** 키보드 조작은 되지만 색약 배려, 글자 크기 조절, 화면 낭독 지원이 약해요.
8. **콘텐츠 분량이 짧아요.** 5스테이지 × 5분이라 유료 게임 기준으로는 짧아요(별·무한·도전으로 보완 중).
9. **음악이 단조로워요.** 3곡 패턴이 반복돼요.
10. **시연 비용.** 타이틀에서도 시뮬레이션이 계속 돌아 저사양에서 배터리를 써요.
11. **이름·상표 확인을 안 했어요.** "갯벌 수호대"를 아직 검색하지 않았어요.

## 9. 다른 AI에게 맡길 분석

아래 질문마다 **근거(파일·줄, 수치)**, **제안**, **예상 작업량(S/M/L)**, **영향(매출·재방문·완성도)**을 붙여 주세요.

### A. 상업성

1. 이 게임을 돈 받고 팔려면 무엇이 가장 부족한가요? (분량, 차별점, 첫인상, 출시 플랫폼)
2. 가격 모델을 비교해 주세요. 한 번 구매, 무료 + 전체 해금, 무료 + 꾸미기 판매, 광고. 부모가 결제한다는 전제와 "광고·확률형 뽑기 없음"이라는 지금 방향에 맞춰야 해요.
3. Steam, 모바일(PWA → Capacitor 래퍼), 웹 포털 중 출시 순서와 각 준비물(등급분류, 스토어 자료, 테스트 기간)을 정리해 주세요.
4. 같은 장르 경쟁작과 비교해 차별점("땅을 되살리는 생존 게임", 우리 바다 생물)을 어떻게 키울까요?

### B. 게임 디자인

1. 첫 60초 안에 회색 땅 → 몬스터 → 초록 땅 → 강해짐이라는 인과를 이해할 수 있나요? 글 없이 더 분명하게 할 방법을 제안해 주세요.
2. 난이도 곡선, 무기 간 균형(어떤 무기가 너무 강하거나 약한지), 진화 조합의 다양성
3. 복원 메커니즘의 전략성. 초록 땅을 지키고 넓히는 선택이 실제로 의미가 있나요?
4. 장기 목표: 진주 경제, 해금 속도, 업적, 오늘의 도전 보상이 적절한지
5. 다음에 넣을 콘텐츠 우선순위: 스테이지, 보스, 캐릭터, 무기, 이벤트, 협동 모드

### C. 기술

1. 구조 검토: sim/render 분리, fx 큐, 데이터 주도 설계의 장단점과 확장 시 문제
2. 저가 휴대폰 성능 위험과 측정 방법, 추가 최적화
3. 저장 데이터 안정성(버전 관리, 손상 대비), 서버 없이 할 수 있는 것과 서버가 필요한 것(랭킹, 클라우드 저장)
4. 테스트 공백: 지금 33개가 놓치는 부분
5. 스토어 출시용 포장(PWA, 오프라인, 아이콘, 세로·가로 화면)

### D. 교육·신뢰

1. 한 줄 지식 51문장의 사실 여부와 더 좋은 표현
2. 부모가 "사 주고 싶은" 게임이 되게 하는 장치(교육 효과를 드러내는 방식, 안전성 표시)

### 산출물 형식

1. 핵심 결론 5줄
2. 영역별(A~D) 발견 사항 표: 문제, 근거, 제안, 작업량, 영향
3. 출시까지 6~8주 로드맵(주 단위)
4. 바로 할 일 10개(우선순위순)
